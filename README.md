# ☁️ Chromebience

Chromebience is a premium ambient sound Chrome extension designed for:

* deep focus
* studying
* sleep
* relaxation
* meditation

Mix multiple ambience sounds together with seamless looping and beautiful modern UI.

## ✨ Features

* Multi-sound ambience mixer
* Seamless audio looping
* Background playback
* Beautiful dark/light themes
* Preset focus modes
* Sleep timer
* Compact premium UI
* Smooth animations
* Pastel ambient aesthetic

## 🌙 Included Ambiences

* Rain
* Thunderstorm
* Ocean Waves
* Fireplace
* Wind
* River
* Birds
* Frogs
* Crickets
* Brown Noise
* White Noise
* Pink Noise
